AEGIS OS v4.1

Security controls for AI agents that have to run in the real world.

AEGIS OS is a Rust-based platform for hardening agent execution with layered controls: policy enforcement, input sanitization, sandboxing, runtime risk scoring, audit trails, red-team simulation, and autonomous reporting.

What It Covers

  • API gateway, RBAC, TLS, and tool routing
  • WASM sandboxing and filesystem/network controls
  • Credential vaulting, capability tokens, and drift detection
  • RAG poisoning, privacy leaks, extraction attempts, and hallucination checks

Autonomous Loop

  • Discover agents
  • Run continuous security tests
  • Analyze and score threats
  • Block risky agents and generate reports

Implemented In

Rust, Tokio, Axum, Wasmtime, Docker, Prometheus, and Grafana. The project ships with CLI workflows, server endpoints, dashboards, and red-team simulations.
